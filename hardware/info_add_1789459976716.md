# Compute Module platform selection

The platform list previously omitted Compute Module boards, and AUTO only matched
Raspberry Pi 4/5 model names. It now also recognizes Raspberry Pi Compute Module
4/5 and accepts explicit `BASE_GPIO_PLATFORM="RPI CM4"` / `"RPI CM5"` values.

CM4 maps to the existing RPI4 GPIO implementation and CM5 maps to RPI5. Source
selection, compile guards, libraries and PWM layouts follow those implementations;
no separate Compute Module GPIO implementation is introduced. The hardware
`info.md` platform section includes these choices and their configuration syntax.
