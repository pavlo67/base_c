# StepperMotorDumb

`StepperMotorDumb` derives from `StepperMotor` and uses its GPIO initialization, cleanup, scheduler, watchdog, and inherited blocking `probe()`. Its constructor adds a requested positive speed in degrees per second, a pause after PWM stops in nanoseconds, and a tolerated number of pulses remaining at completion. The speed is an upper bound; the movement angle passed to `prepare()` or `probe()` is rounded to a pulse count with `degPulse`, and its sign sets direction.

The class builds one `StepperMotorSeries` with equal initial and final speeds, zero acceleration, and `LINEAR_INTERVAL_ACCELERATION`. It chooses the highest integer PWM frequency no greater than the requested speed, configured speed/frequency limits, the GPIO 10000-Hz limit, the pulse-width limit, and `(tolerance + 1) / timerInterval`. The selected rounded nanosecond period is checked against that timer bound as well. For targets shorter than the requested tolerance, the effective tolerance is `targetPulses - 1`. A zero configured timer uses the inherited 1-us polling cadence. A move is rejected if these bounds leave no valid integer-Hz frequency. Acceleration statistics are zeroed because this executor does not model acceleration or braking.

At each `action()` call after the GPIO setup guard, the execution model counts periods at the fixed frequency. The first call that sees at most the effective tolerance remaining disables STEP PWM. ENA remains active during the configured pause, then inherited `stop()` disables the motor and returns `COMPLETE`. The pause is part of the watchdog time. The frequency rule keeps the *modeled* count at or below the target when calls arrive on the expected timer grid. Late calls can still overshoot. The GPIO API does not report physical pulse edges, so the result is a PWM-model estimate rather than a guaranteed hardware edge count.

`stepper_motor_dumb_test.cpp` checks fixed interval planning, frequency capping, near-target completion, pause behavior, and inherited `probe()` on the desktop GPIO backend.
