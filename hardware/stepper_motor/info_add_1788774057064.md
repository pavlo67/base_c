# Corrections to the previous stepper motor documentation

The former GPIO execution description referred to software-sleep pulse replay through `move()`. It is replaced by stateful `StepperMotorAction::action(moment)` and timer-driven `run()`, using the GPIO PWM API. The primary `info.md` now documents return codes, setup guards, watchdog, cleanup, commanded-frequency estimates and backend limitations.

Accelerated zero-base-speed moves reserve one of their requested pulses for a finite terminal interval. The default 90-degree clocked case remains 400 pulses: 200 acceleration, 199 primary braking and one slow final pulse. Final speed remains an interval-average quantity, normally 2.25 deg/s; no inferred mechanical zero or settling time is reported.

Probe output now includes runtime `real`, grouped phase totals and optional details. Configuration defaults are VERBOSE=false and HARDWARE_PWM=true, with a desktop Warning/OFF fallback. In this checkout the configuration template is at the repository root. The probe hardware-PWM STEP pin is explicitly BCM18, while software mode retains BCM17.

The old statements that all statistics exclude runtime timing, that the probe never reconfigures PWM, and that every 90-degree sequence contains exactly two internal sections no longer apply. See `info.md` for the current contracts and measurement limitations.
