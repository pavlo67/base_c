# Natural terminal period

Removed the fixed 100-ms minimum from rest-to-rest move planning. The reserved
last pulse remains part of the target displacement and the Deceleration statistics.
Its period is now the single-pulse kinematic duration determined by degrees/pulse,
maximum speed, maximum frequency and acceleration. Timer quantization and live
PWM overshoot still apply. Existing historical timing examples that include a
100-ms terminal period no longer describe current results.

GTest/CTest covers one/two-pulse moves, signed 0.25/1/2-degree platform moves,
slow single-pulse motion, timer rounding and live braking after delayed calls.
