# Stepper pulse interval algorithms

`pulse_series_t` supports two explicitly selectable interval algorithms.

- `pulse_interval_algorithm_t::constantAcceleration` is the default. The series stores absolute `initialSpeed` and signed `acceleration`. `intervalSec(pulseIndex, stepperOpts)` derives every interval from the exact constant-acceleration kinematics over one pulse distance. No interval array is stored.
- `pulse_interval_algorithm_t::linearIntervalFallback` retains the earlier algorithmic approximation. It uses `initialIntervalSec + intervalChangePerPulse * pulseIndex`. It is intended for comparison, diagnostics, or a simple fallback rather than as the normal motion profile.

`calculateAction()`, `getFastestSeries()`, and `getAcceleratedSequence()` accept the interval algorithm as an optional final argument and default to `constantAcceleration`.

For the exact algorithm, the interval of pulse `n` is calculated from the speeds at the beginning and end of that pulse distance:

`interval = 2 * degreesPerPulse / (speedBefore + speedAfter)`.

The fallback fields remain populated for every generated series, so the same planned profile can be requested with either algorithm.
