# pulses_probe timing clarification

`STEP_LOW_US` uses `1e6` to calculate microseconds and is passed to
`std::chrono::microseconds`. With `SPEED_DEG_S=20`, the low interval is
11,235 microseconds. The startup message divides this value by `1e3` and
reports 11.235 ms. With the configured 15-us high interval in
`_env/machina.yaml`, the requested total pulse period is 11.25 ms;
GPIO calls and scheduling can lengthen the actual period. The previous
unit mismatch caused a low interval of about 11.25 seconds.
