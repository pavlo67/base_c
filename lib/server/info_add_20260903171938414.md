# Correction: Mongoose server shutdown

Mongoose shutdown is intentionally two-phase. `stopServer()` requests event-loop termination without joining the server thread. The thread owner calls `waitForServerStopped()` to join and reset server state. This allows `stopMachina()` to signal a `runMachina()` thread which is already waiting for the server to finish.

`server_http_mngs_test` uses scoped cleanup that performs both operations, including when a fatal test assertion unwinds the test case.
